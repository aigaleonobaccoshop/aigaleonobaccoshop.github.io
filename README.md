# InStore Assistant — public information site

Static presentation, privacy policy and terms for the existing Apps Script application.
No app database, credentials or Google OAuth tokens are included.

Files: index.html, privacy.html, terms.html, assets/style.css, assets/logo.png, .nojekyll.

Publish at the root of the public repository aigaleonobaccoshop.github.io.
GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save.
The expected site address is https://aigaleonobaccoshop.github.io/ once GitHub confirms deployment.

Google Search Console: add the exact HTTPS site URL as a URL-prefix property,
using the same Google account that administers the Nobacco Access Cloud project.
Use HTML-file verification. Add the exact downloaded verification file to the
repository root, wait for Pages deployment, then Verify. Keep the file published.

Only after the site is live and ownership verified, enter these URLs in Branding:
Homepage: https://aigaleonobaccoshop.github.io/
Privacy: https://aigaleonobaccoshop.github.io/privacy.html
Terms: https://aigaleonobaccoshop.github.io/terms.html
Authorized domain: aigaleonobaccoshop.github.io

Google may request further information. This package does not establish that
branding has been accepted or Production publication has completed.
The app remains on its existing Apps Script URL.

Privacy text describes Personal Drive v3, including server-side refresh tokens,
administrator access, 7-day daily-copy retention target and retained legacy copies.
It does not describe the unfinished, uninstalled encryption prototype.
